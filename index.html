Pengaturan Koneksi Hardware Arduino

Website ini dapat berjalan mandiri (Mode Simulasi) atau dihubungkan langsung ke mikrokontroler seperti Arduino dengan WiFi ESP8266, ESP32, atau Webhook.

Contoh endpoint JSON sensor: http://192.168.1.50/data
Contoh: akan memanggil http://192.168.1.50/feed?gram=25

💡 Contoh Hardware yang digunakan:

  • Sensor Suhu: DS18B20 (Waterproof) terpasang di Pin D4
  • Sensor Kekeruhan: Turbidity Sensor Gravity Analog di Pin A0
  • Motor Pakan: Servo MG995 / Stepper Motor terpasang di Pin D2
  • Mikrokontroler: ESP32 / ESP8266 NodeMCU terhubung ke WiFi rumah
